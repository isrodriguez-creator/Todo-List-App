# Todo-List-App

Mini aplicación web de "Lista de Tareas" (To-Do List) desarrollada como proyecto final de la Unidad 4 — Metodología de Desarrollo de Software (DAWA-202), aplicando el ciclo completo de **SCRUM** con **Jira**, **GitHub** y **CI (Jenkins / GitHub Actions)**.

## Descripción

Aplicación web sencilla hecha con HTML, CSS y JavaScript puro (sin frameworks) que permite:

- Agregar una nueva tarea
- Marcar una tarea como completada
- Eliminar una tarea
- Editar el texto de una tarea
- Filtrar tareas (todas / pendientes / completadas)
